# ✅ Task Tracker

Lista de tarefas feita com HTML, CSS e JavaScript puro. As tarefas ficam salvas no navegador.

🔗 **Demo:** https://santisantos13.github.io/task-tracker-js/

## Funcionalidades

- Adicionar tarefas (botão ou Enter)
- Marcar como concluída com um clique
- Remover tarefas
- Salvar no navegador com `localStorage`

## Tecnologias

HTML, CSS e JavaScript

## Como rodar

Baixe o projeto e abra o arquivo `index.html` no navegador.
